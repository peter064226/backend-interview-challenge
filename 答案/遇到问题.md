# 遇到的问题和解决方法

1. src/orders/orders.service.ts(37,58): error TS2345: Argument of type 'Order' is not assignable to parameter of type 'Record<string, unknown>'.
   
   **fix**: The putItem method in the DynamoDB service expects a Record<string, unknown> type, but the Order interface is a specific typed interface. The TypeScript compiler is being strict about this type mismatch.
   The fix is to cast the Order object to Record<string, unknown> when passing it to the putItem method. 
   
   ```typescript
   await this.dynamoDBService.putItem(ORDERS_TABLE,order as unknown as Record<string, unknown>);
   ```
   
   
   
2. [API] [Nest] 2822  - 01/15/2026, 11:02:12 AM     LOG [OrdersController] 📦 Creating order: {"customerId":"cust-123","items":[{"productId":"prod-1","productName":"Test Product","quantity":2,"unitPrice":29.99}],"totalAmount":59.98}
    [API] [Nest] 2822  - 01/15/2026, 11:02:12 AM   ERROR [ExceptionsHandler] Unsupported type passed: [object Object]. Pass options.convertClassInstanceToMap=true to marshall typeof object as map attribute.
    
    **fix**: The error shows that DynamoDB is having trouble marshalling the data because it contains class instances (likely from the DTO). The AWS SDK needs plain objects. need to convert these to plain objects. The simplest fix is to serialize the order object to JSON and back to ensure it's a plain object
    
    ```typescript
    await this.dynamoDBService.putItem(
                ORDERS_TABLE,
                JSON.parse(JSON.stringify(order)) as Record<string, unknown>
            );
    ```
